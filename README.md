# 陳家蜂蜜養蜂智庫

這是一套可公開部署的響應式 PWA 網站：桌機、平板與手機共用同一網址並自動切版。訪客不需登入即可查詢知識庫、使用問答與查看枋山即時天氣；手機瀏覽器可將網站加到主畫面，作為 App 使用。

## 本機預覽

在此資料夾執行：

```powershell
python -m http.server 8080
```

瀏覽器開啟 `http://localhost:8080`。不要直接雙擊 `index.html`，因為離線快取與部分瀏覽器功能需要 HTTP。

## 公開上線

可直接部署到 Cloudflare Pages、Netlify、GitHub Pages 或既有 `bee-chen.com` 主機的子目錄。部署根目錄就是本資料夾，不需編譯，也不需伺服器或 API 金鑰。正式建議使用例如 `https://knowledge.bee-chen.com`，並由原官網加上「養蜂智庫」入口。

目前「問智庫」是公開、免費、無登入的本地知識檢索版。若未來要讓任何長尾問題都能生成回答，需另建後端串接大型語言模型；API 金鑰只能放在後端環境變數，不可寫入前端 `script.js`。

## 資料維護

問答與知識卡都在 `script.js` 的 `knowledge` 陣列。新增一筆即可同時出現在知識庫搜尋與問答比對。資料來源不包含苗栗區農業改良場。
